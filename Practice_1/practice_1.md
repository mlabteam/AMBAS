## Введение

Цель данной практической работы - подготовить и развернуть программное окружение для моделирования беспилотных авиационных систем на базе автопилота ArduPilot в операционной системе Ubuntu 24.04 LTS, а также освоить подключение и управление через наземную станцию управления Mission Planner.

Задачи данной практической работы:

* Установить операционную систему Ubuntu 24.04 LTS;
* Клонировать исходный код ArduPilot, установить зависимости с помощью скриптов и собрать симулятор SITL для платформы ArduCopter;
* Установить и настроить наземную станцию управления Mission Planner в ОС Ubuntu;
* Запустить симулятор ArduPilot SITL через командную строку;
* Подключить Mission Planner к симулятору;
* Выполнить базовые команды управления симулируемым аппаратом (смена полетных режимов, арминг, автоматический взлет, полет по точке и посадка).

## Выполнение практической работы

### Этап 1 - Установка Ubuntu 24.04 LTS

1. Скачайте образ операционной системы с [официального сайта Ubuntu](https://ubuntu.com/download/desktop).
2. Создайте загрузочный носитель (например, с помощью утилиты Rufus или BalenaEtcher) и выполните установку ОС на ваш ПК, следуя [официальному руководству](https://ubuntu.com/tutorials/install-ubuntu-desktop).
3. После завершения установки и загрузки системы откройте терминал (сочетание клавиш `Ctrl + Alt + T`).
4. Обновите списки пакетов и установленные программы:
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```
> 
>  Для вставки и копирования текста в терминале Ubuntu используются сочетания клавиш `Ctrl + Shift + V` и `Ctrl + Shift + С`
>

### Этап 2 - Установка Visual Studio Code

Среда разработки Visual Studio Code значительно упрощает работу с исходным кодом и терминалом в среде Linux.

1. Установите VS Code из официального магазина Snap, выполнив в терминале команду:
   ```bash
   sudo snap install code --classic
   ```
   > Также вы можете скачать `.deb` пакет с [официального сайта](https://code.visualstudio.com/) и установить его через менеджер пакетов или двойным кликом.

2. Запустите VS Code через меню приложений или выполнив в терминале команду:
   ```bash
   code
   ```

3. Откройте встроенный терминал в VS Code (сочетание клавиш `` Ctrl + ` `` или меню *Terminal -> New Terminal*) - в нижней части экрана откроется bash-терминал, в котором будет удобно выполнять все дальнейшие команды, находясь в интерфейсе редактора.

### Этап 3 - Клонирование репозитория ArduPilot и настройка окружения

Все действия данного этапа выполняются в терминале.

1. Установите систему контроля версий Git:
   ```bash
   sudo apt install git -y
   ```

2. Перейдите в домашнюю директорию и склонируйте официальный репозиторий ArduPilot со всеми вложенными подмодулями (submodules):
   ```bash
   cd ~
   git clone --recurse-submodules https://github.com/ArduPilot/ardupilot.git
   ```
   > Клонирование может занять некоторое время в зависимости от скорости интернетае.

3. Перейдите в директорию склонированного репозитория:
   ```bash
   cd ~/ardupilot
   ```

4. Запустите скрипт автоматической установки необходимых зависимостей для Ubuntu:
   ```bash
   Tools/environment_install/install-prereqs-ubuntu.sh -y
   ```
   > Запускайте данный скрипт от имени обычного пользователя, а НЕ через `sudo`! Скрипт сам запросит права суперпользователя при необходимости. Запуск через `sudo` нарушит права доступа к файлам окружения и путям Python.

5. Посте завершения выполнения скрипта обязательно **перезагрузите компьютер**

6. Проверьте корректность настройки путей командой:
   ```bash
   which sim_vehicle.py
   ```
   Должен вернуть путь вида: `/home/<ваше_имя>/ardupilot/Tools/autotest/sim_vehicle.py`.

### Этап 4 - Установка Mission Planner в Ubuntu

Наземная станция управления Mission Planner изначально разработана для Windows, однако она успешно запускается в Linux с использованием платформы Mono.

1. Установите Mono, выполнив в терминале следующие команды:
   ```bash
   sudo apt install gnupg ca-certificates
   sudo apt-key adv --keyserver hkp://keyserver.ubuntu.com:80 --recv-keys 3FA7E0328081BFF6A14DA29AA6A19B38D3D831EF
   echo "deb https://download.mono-project.com/repo/ubuntu stable-focal main" | sudo tee /etc/apt/sources.list.d/mono-official-stable.list
   sudo apt update
   sudo apt install mono-complete -y
   ```

2. Скачайте архив с Mission Planner (в формате `.zip`) с [официального сайта](https://firmware.ardupilot.org/Tools/MissionPlanner/MissionPlanner-latest.zip).
3. Распакуйте архив в удобную директорию (например, `~/MissionPlanner-latest`).
4. Для запуска Mission Planner перейдите в папку с распакованными файлами и выполните команду:
   ```bash
   cd ~/MissionPlanner-latest
   mono MissionPlanner.exe
   ```
5. После запуска вы увидите главный экран программы. В правом верхнем углу расположен блок подключения: выпадающий список типов подключения, скорость и кнопка Connect

### Этап 5 - Запуск ArduPilot SITL 

Сборка и запуск программного симулятора осуществляется с помощью скрипта `sim_vehicle.py` из командной строки. В рамках данного курса мы будем работать с мультироторными БАС, поэтому запуск выполняется из директории `ArduCopter`.

1. В терминале Ubuntu перейдите в папку с кодом ArduCopter:
   ```bash
   cd ~/ardupilot/ArduCopter
   ```

2. При первом запуске рекомендуется выполнить очистку EEPROM и сброс параметров флагом `-w` (wipe):
   ```bash
   sim_vehicle.py -w
   ```
   Система автоматически соберет исполняемый бинарный файл `arducopter` для архитектуры SITL, сконфигурирует параметры по умолчанию и запустит консоль MAVProxy.

1. После успешного первого запуска остановите симулятор нажатием сочетания клавиш `Ctrl + C` в терминале.

> 
> Всегда завершайте программы через сочетания клавиш `Ctrl + C` в терминале, а не через нажатие на "Крестик" в окне программы
> 

3. Для стандартного запуска симуляции выполните команду:
   ```bash
   sim_vehicle.py -v ArduCopter --console --map
   ```
   * Параметр `-v ArduCopter` указывает тип аппарата (мультикоптер);
   * Параметры `--console` и `--map` открывают графическую консоль и окно карты MAVProxy для наглядного контроля.

5. При запуске `sim_vehicle.py` автоматически активируется консольная утилита MAVProxy, которая:
   * подключается к ядру симулятора ArduPilot;
   * начинает трансляцию пакетов MAVLink по локальной сети, в частности по протоколу UDP на локальные порт `127.0.0.1:14550`.

### Этап 6 - Подключение Mission Planner к ArduPilot SITL

После того как симулятор запущен в терминале Ubuntu и в консоли MAVProxy появились сообщения о статусе (например, `EKF3 IMU0 is using GPS`, `GPS 3D Fix`), можно производить подключение наземной станции.

1. Перейдите в окно запущенной программы Mission Planner.

2. В правом верхнем углу интерфейса:
   * В выпадающем списке интерфейсов выберите **UDP**;
   * Нажмите кнопку **Connect**;
   * В появившемся диалоговом окне ввода порта введите значение **14550** (порт по умолчанию для трансляции MAVLink из SITL) и нажмите **OK**.

3. После нажатия кнопки Connect начнется загрузка параметров аппарата (окно «Getting Params...»). Дождитесь завершения загрузки параметров.

4. Убедитесь в успешном подключении:
   * Кнопка **Connect** изменит надпись на **Disconnect**;
   * На панели авиагоризонта (HUD) во вкладке **DATA** отобразятся текущий полетный режим (например `STABILIZE`), напряжение батареи, статус GPS (`GPS: 3D Fix`);
   * На карте отобразится иконка квадрокоптера в точке начального старта симулятора.

### Этап 7 - Тестовый полет

Управление можно осуществлять как через терминал MAVProxy в Ubuntu, так и через интерфейс Mission Planner. Выполним базовые полетные операции через консоль MAVProxy:

1. В терминале симулятора переведите аппарат в режим управляемого полета **GUIDED**:
   ```
   mode guided
   ```
   В терминале и в Mission Planner статус режима сменится на `GUIDED`.

2. Выполните процедуру арминга:
   ```
   arm throttle
   ```
   Система выполнит предполетные проверки и при успешном прохождении статус на HUD сменится на `ARMED`.

3. Отдайте команду на автоматический взлет на высоту 10 метров:
   ```
   takeoff 10
   ```

4. Выполните полет к произвольной точке с помощью Mission Planner:
   * На карте во вкладке **DATA** нажмите правой кнопкой мыши в любой точке рядом с коптером;
   * В контекстном меню выберите **Fly to Here**;
   * В появившемся окне укажите высоту полета (например, `15` метров) и подтвердите команду;
   * Наблюдайте движение квадрокоптера к целевой точке.

5. Верните аппарат в точку старта и совершите посадку:
   ```
   mode rtl
   ```
   (Return to Launch - возвращение к точке старта и последующая автоматическая посадка). 
   Либо для немедленной посадки в текущей точке:
   ```
   mode land
   ```

6. После касания земли и остановки винтов статус перейдет в состояние `DISARMED`.
