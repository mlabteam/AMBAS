## Введение

Цель данной практической работы — подготовить и развернуть программное окружение для моделирования беспилотных авиационных систем на базе автопилота **ArduPilot** в операционной системе Windows 11 с использованием подсистемы **WSL2 (Ubuntu)**, а также освоить подключение и управление через наземную станцию управления **Mission Planner**.

Задачи данной практической работы:

* Установить и настроить подсистему WSL2 с операционной системой Ubuntu на ПК под управлением Windows 11;
* Клонировать исходный код ArduPilot, разрешить зависимости с помощью скриптов окружения и собрать симулятор SITL для платформы ArduCopter;
* Установить и настроить наземную станцию управления Mission Planner в ОС Windows 11;
* Запустить симулятор ArduPilot SITL;
* Подключить Mission Planner к симулятору;
* Выполнить базовые команды управления симулируемым аппаратом (смена полетных режимов, арминг, автоматический взлет, полет по точке и посадка).

## Выполнение практической работы

### Этап 1 — Установка WSL2 и развертывание Ubuntu в Windows 11

1. Откройте терминал **PowerShell** от имени **Администратора** (нажмите правой кнопкой мыши по меню «Пуск» -> *Терминал (Администратор)*).

2. Запустите установку дистрибутива Ubuntu:
   ```powershell
   wsl --install -d Ubuntu
   ```
   > После завершения процесса требуется перезагрузка компьютера. После перезагрузки процесс установки продолжится автоматически.

3. После завершения распаковки откроется окно терминала Ubuntu с предложением создать пользователя:
   * **Enter new UNIX username**: введите имя пользователя (только строчные латинские буквы без пробелов, например, ваше имя или логин);
   * **New password**: введите пароль (при вводе символы не отображаются на экране — это нормальное поведение терминала Linux);
      > Рекомендуется ставить простой пароль для быстрого подтверждения sudo 
   * **Retype new password**: повторите ввод пароля.

4. Проверьте статус и версию установленного дистрибутива в PowerShell:
   ```powershell
   wsl -l -v
   ```
   В выводе должно быть указано имя `Ubuntu`, статус `Running` или `Stopped`, и версия `2`.

5. Откройте терминал Ubuntu (через меню «Пуск» -> *Ubuntu* или команду `wsl -d Ubuntu` в терминале) и обновите списки пакетов и установленные программы:
   ```bash
   sudo apt update && sudo apt upgrade -y
   ```

### Этап 2 — Установка Visual Studio Code и интеграция с WSL

Интегрированная среда разработки (IDE) Visual Studio Code (VS Code) значительно упрощает работу с исходным кодом и терминалом. Благодаря расширению WSL, вы можете использовать VS Code в Windows для редактирования файлов и выполнения команд непосредственно в среде Linux.

1. Скачайте инсталлятор **Visual Studio Code** с [официального сайта](https://code.visualstudio.com/) для Windows и выполните установку (при установке рекомендуется оставить настройки по умолчанию).

2. Запустите VS Code. Перейдите в раздел расширений (Extensions, сочетание клавиш `Ctrl + Shift + X`).

3. В строке поиска введите **WSL**  и нажмите **Install**.

4. В левом нижнем углу нажмите на значок **Open a Remote Window** и выберете **Connect to WSL**.
   > При первом запуске подсистема автоматически скачает и установит серверную часть VS Code для Linux, в правом нижнем углу будет процесс загрузки.

5. Откроется новое окно VS Code. В левом нижнем углу окна (в строке состояния) будет отображаться синий значок с надписью **WSL: Ubuntu**, что подтверждает успешное подключение к файловой системе и окружению Linux. 

6. Откройте встроенный терминал в VS Code (сочетание клавиш `` Ctrl + ` `` или меню *Terminal -> New Terminal*) — перед вами откроется полноценный bash-терминал Ubuntu, в котором будет удобно выполнять все дальнейшие команды.

### Этап 3 — Клонирование репозитория ArduPilot и настройка окружения

Для работы с симулятором требуется исходный код ArduPilot и набор компиляторов и утилит Python. Все действия данного этапа выполняются **внутри терминала Ubuntu**.

1. Установите систему контроля версий Git (если она еще не установлена):
   ```bash
   sudo apt install git -y
   ```

2. Перейдите в домашнюю директорию и склонируйте официальный репозиторий ArduPilot со всеми вложенными подмодулями (submodules):
   ```bash
   cd ~
   git clone --recurse-submodules https://github.com/ArduPilot/ardupilot.git
   ```
   > Клонирование подмодулей может занять некоторое время в зависимости от скорости интернет-соединения.

3. Перейдите в директорию склонированного репозитория:
   ```bash
   cd ~/ardupilot
   ```

4. Запустите скрипт автоматической установки необходимых зависимостей для Ubuntu:
   ```bash
   Tools/environment_install/install-prereqs-ubuntu.sh -y
   ```
   > **КРАЙНЕ ВАЖНО:** Запускайте данный скрипт **от имени обычного пользователя**, а **НЕ** через `sudo`! Скрипт сам запросит права суперпользователя при необходимости. Запуск через `sudo` нарушит права доступа к файлам окружения и путям Python.

5. Чтобы применить изменения путей окружения (PATH) без перезапуска терминала, выполните:
   ```bash
   source ~/.bashrc
   ```

6. Проверьте корректность настройки путей. Команда:
   ```bash
   which sim_vehicle.py
   ```
   должна вернуть путь вида: `/home/<ваше_имя>/ardupilot/Tools/autotest/sim_vehicle.py`.

### Этап 4 — Установка Mission Planner в Windows 11

Наземная станция управления (Ground Control Station, GCS) Mission Planner будет запускаться непосредственно в хостовой системе Windows 11.

1. Перейдите на официальный сайт загрузки ПО ArduPilot и скачайте последнюю версию инсталлятора Mission Planner (файл `.msi`):
   [Скачать Mission Planner (Latest MSI)](https://firmware.ardupilot.org/Tools/MissionPlanner/MissionPlanner-latest.msi)

2. Запустите скачанный файл инсталлятора и следуйте инструкциям мастера установки. При появлении запросов на установку драйверов устройств (Device Drivers) согласитесь на установку.

3. Запустите **Mission Planner** из меню «Пуск» Windows.

4. В правом верхнем углу расположен блок подключения: выпадающий список типов подключения (COM-порты, TCP, UDP), скорость бод (Baud rate) и кнопка **Connect**.

### Этап 5 — Запуск ArduPilot SITL (ArduCopter)

Сборка и запуск программного симулятора осуществляется с помощью скрипта `sim_vehicle.py`. В рамках данного курса мы будем работать с мультироторными БАС, поэтому запуск выполняется из директории `ArduCopter`.

1. В терминале Ubuntu перейдите в папку с кодом ArduCopter:
   ```bash
   cd ~/ardupilot/ArduCopter
   ```

2. При первом запуске рекомендуется выполнить очистку EEPROM и перезагрузку параметров флагом `-w` (wipe):
   ```bash
   sim_vehicle.py -w
   ```
   Система автоматически соберет исполняемый бинарный файл `arducopter` для архитектуры SITL, сконфигурирует параметры по умолчанию и запустит консоль MAVProxy.

3. После успешного первого запуска остановите симулятор нажатием сочетания клавиш `Ctrl + C` в терминале.

4. Для стандартного запуска симуляции выполните команду:
   ```bash
   sim_vehicle.py -v ArduCopter --console
   ```
   * Параметр `-v ArduCopter` указывает тип аппарата (мультикоптер);
   * Параметр `--console` открывает графическую консоль MAVProxy (благодаря поддержке WSLg в Windows 11 графические окна Linux открываются прямо на рабочем столе Windows). Если графическая консоль не требуется, данный флаг можно опустить.

5. При запуске `sim_vehicle.py` автоматически активируется MAVProxy, который:
   * подключается к ядру симулятора ArduPilot;
   * начинает трансляцию пакетов MAVLink по протоколу UDP на локальные порты `127.0.0.1:14550` и `127.0.0.1:14551`.

> 💡 **Примечание по сетевому взаимодействию WSL2 и Windows 11:**
> Подсистема WSL2 в Windows 11 по умолчанию поддерживает автоматическую переадресацию локального адреса (*localhost forwarding*). Это означает, что сетевой трафик, отправляемый в WSL2 на `127.0.0.1`, доступен приложениям в Windows 11 по адресу `127.0.0.1` (localhost).

### Этап 6 — Подключение Mission Planner к ArduPilot SITL

После того как симулятор запущен в терминале Ubuntu и в консоли появились сообщения вида `EKF3 IMU0 is using GPS`, `GPS 3D Fix`, можно производить подключение наземной станции.

1. Перейдите в окно программы **Mission Planner** в Windows 11.

2. В правом верхнем углу интерфейса:
   * В выпадающем списке интерфейсов выберите **UDP**;
   * Нажмите кнопку **Connect**;
   * В появившемся диалоговом окне ввода порта введите значение **14550** (порт по умолчанию для трансляции MAVLink из SITL) и нажмите **OK**.


3. После нажатия кнопки Connect начнется загрузка параметров аппарата (окно «Getting Params...»). Дождитесь завершения загрузки параметров.

4. Убедитесь в успешном подключении:
   * Кнопка *Connect* изменит надпись на **Disconnect**;
   * На панели авиагоризонта (HUD) во вкладке **DATA** отобразятся текущий полетный режим (`STABILIZE`), напряжение батареи, статус GPS (`GPS: 3D Fix`) и искусственный горизонт;
   * На карте отобразится иконка квадрокоптера в точке начального старта симулятора.

### Этап 7 — Верификация работы и тестовый полет

Для подтверждения полной работоспособности развернутого стенда необходимо выполнить тестовый полет симулируемого аппарата.

Управление можно осуществлять как через терминал MAVProxy в Ubuntu, так и через интерфейс Mission Planner. Выполним базовые полетные операции через консоль MAVProxy:

1. В терминале симулятора переведите аппарат в режим управляемого полета **GUIDED**:
   ```
   mode guided
   ```
   В терминале и в Mission Planner статус режима сменится на `GUIDED`.

2. Выполните процедуру арминга (снятия с предохранителя / запуск моторов):
   ```
   arm throttle
   ```
   Система выполнит предполетные проверки и при успешном прохождении статус на HUD сменится на `ARMED`.

3. Отдайте команду на автоматический взлет на высоту 10 метров:
   ```
   takeoff 10
   ```

4. Выполните полет к произвольной точке с помощью Mission Planner:
   * На карте во вкладке **DATA** нажмите правой кнопкой мыши в любой точке рядом с коптером;
   * В контекстном меню выберите **Fly to Here**;
   * В появившемся окне укажите высоту полета (например, `15` метров) и подтвердите команду;
   * Наблюдайте движение квадрокоптера к целевой точке.

5. Верните аппарат в точку старта и совершите посадку:
   ```
   mode rtl
   ```
   (Return to Launch — возвращение к точке старта и последующая автоматическая посадка). 
   Либо для немедленной посадки в текущей точке:
   ```
   mode land
   ```

6. После касания земли и остановки винтов статус перейдет в состояние `DISARMED`.
